# SSMCP 0.10.41

## 项目工作区

- Linux 管道命令可以申请项目内的独立工作目录。SSMCP 在 `.ssmcp/workspace/jobs/` 中分配目录，并通过 `SSMCP_PROJECT_ROOT` 给出项目根路径。临时任务释放后，客户端根据进程和产物的实际状态决定回收或保留。
- Linux 和 macOS 的 `ssmcp worktree create` 创建登记过的 Git 工作树。完成工作后按 ID 释放，默认保留 24 小时。启动、定期和重新加载时的清理都使用项目配置，`ssmcp cleanup --dry-run` 可以预览。活动租约、未提交文件和未并入项目的提交受到保留。
- 旧目录可移入项目恢复区。`.ssmcp/recovery/` 中的人工备份不参与临时文件回收。[工作区操作示例](workspaces.md#放在项目内的临时工作区)

## 同期更新

空闲工作进程可以等待容量变化，调度器可成批等待任务结果。即时读取已有结果时，界面按快照展示。Termux 增加了校验发行文件和从源代码安装的入口。
