# SSMCP 0.10.38

## 终端与协作

- 主对话标题栏显示当前协调者的工作状态。窄窗口优先保留角色和状态。新客户端能区分维护待开始、持续 Dreaming、正在工作、空闲以及离线；缺少状态证据时显示 Unknown。
- 默认空闲满 5 分钟后进入低功耗维护。单个维护动作默认预算 30 秒。生命周期单独记录连续 Dreaming 的开始时间和已持续时长；新的用户输入或工作认领使成员回到 Working。
- 主协调者与 worker 的指引要求连续 Dreaming 至少 30 分钟才可申请主动退出。必须收到对应申请的人类明确同意。人类拒绝后要再等完整 30 分钟，待答的申请沿用原编号。断线、失联和租约到期单独记录。
- 首次绑定或重新接入时，邀请指出如何用 `await skills.view(clientId, {})` 查看已获授权的技能概览。
- 普通 worker 进度页或失效游标重复出现时，自动提醒在 5 分钟内合并。显式读取仍可取得完整事件；失败、未知结果和新输入继续独立交付。事件游标由确认操作推进。

## 执行、剪贴板与扩展

- 管道命令可显式提供输入版本以合并相同的在途请求，并为完整成功结果设置有效期。默认执行方式保持独立。返回回执区分新启动、加入已有任务和命中缓存。
- Linux 剪贴板接受带大小写、空格或引号的 UTF-8 文本 MIME 参数。浏览器同时提供网页 URL 列表与纯文本时，可粘贴其文本表示。包含本地与远程地址的混合文件列表仍按原文件校验规则处理。
- 工具仓库入口支持常用的 `./dist/tools.js` 写法。兼容更新了 TOML 解析和编辑依赖。
- 发行归档根据应用的 Cargo 锁文件构建配套 zrun。Linux 默认交互路径由 zrun 原生解析并执行；支持目录切换、导出变量、管道、重定向、命名异步任务和等待。提示符显示目录、Git 分支与失败退出码。已有 Unix 安装器会保留用户自己安装的 zrun。

## 测量范围

在 i9-12900HX 开发机的三轮只读管道基准中，每轮每种模式发起 1,000 次请求。在途合并将实际进程启动数从每轮 1,000 降至 63；预热后的缓存请求没有新增进程。默认独立执行与缓存适用的输入条件不同。重复进度提醒使用相同事件页的合成回归测量，首次之后连续 100 次返回均未增加提醒内容。
