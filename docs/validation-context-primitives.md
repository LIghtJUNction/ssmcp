## 覆盖的行为

技能索引保留名称、描述和路径来源；同名技能不互相覆盖，正文按需读取。测试覆盖引号和多行元数据、BOM、CRLF、UTF-8、缺失或不支持的元数据、分页游标及扫描预算。

AGENTS 视图按所选根到目标路径返回指令来源，验证 override、空文件回退、小写文件、缺失目标、兄弟目录排除及内容上限。附加上下文根需要显式选择，普通文件接口不能通过该配置获得根外写入能力。

文件测试覆盖二进制接口兼容、UTF-8 分页、精确匹配、陈旧 SHA-256、并发原生编辑只产生一个成功者、权限和换行保持、符号链接与非普通文件拒绝，以及有限锁等待。

这些视图表示显式目录中的当前磁盘内容。技能摘要由 frontmatter 的 name/description 生成，解析范围在返回值与使用说明中公开；返回文档不会执行命令或调用模型。
