# 手机控制与终端交互

在 KernelSU 或 Magisk 的 SSMCP WebUI 中，轻点卡片可展开详情，单指上下滑动可滚动所在面板。要输入文字，点光标所在行或底部键盘按钮。窄屏保留了展开快捷键提示。

终端保留 ANSI 调色板、RGB 真彩色、文字背景和常用样式，按实际列宽排列中文与组合字符。画面未变时复用上一帧，局部变更时只更新相关行。

各标签按顺序发送输入。大段粘贴按 UTF-8 边界分块，上一块收到回执后再发送下一块。连接中断时，当前标签会分别保留回执未确认的内容与尚未发送的内容，可手动复制恢复。

手机上运行 `zuse web` 后，从终端标签栏点「Zuse」即可打开本机工作台。手机浏览器通过 `/zuse` 内嵌工作台，KernelSU 管理器通过系统浏览器打开。工作台的本机地址为 `http://127.0.0.1:43497/`。

在 Chromium 158 的模拟慢连接测试中，粘贴 1 MiB ASCII 并等待首笔回执期间，JavaScript 堆与后备存储合计从 21.46 MiB 降至 2.48 MiB。这个数字描述浏览器输入队列，占用会随设备、页面内容和连接状态而变化。

当两个会话使用相同显示名时，收件人列表会同时显示各自的 ID 后缀、摘要和近期工具调用次数，方便在窄屏确认消息发往哪一个会话。

使用账户中继时，请先确认服务端支持控制器准入握手。旧中继可在设备注册前关闭连接，客户端会等待后重试。更新共享中继前可保留原客户端在线，先用新版本做一次独立的真实账号连接检查。
