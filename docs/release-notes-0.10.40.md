# SSMCP 0.10.40

## 时间与长任务

- 等待窗口保留毫秒精度。6500ms 的窗口显示为 `00:06.500`。事件触发后显示实际已用时间，停止展示倒计时。失去中继观察时，已用与剩余时长取自同一个单调时间点。
- 一份原生命令回执同时观察到子进程退出和取消时，管道与 PTY 路径优先保留已取得的退出码或终止信号。仍在运行的任务可以取消或按执行期限结束。
- 分页读取分别跟踪标准输出与错误输出的游标。收到可交付的页面或进程终态时，事件卡标记为已触发。没有新数据时才显示等待窗口到期。
- 工作区显式关闭自己持有的 TCP 句柄时，会先唤醒等待中的操作，再等系统资源和并发配额释放后返回成功回执。

README 和时间文档说明了时间敏感工作的工程目标，区分时钟精度、事件到回执的外部耗时，以及重连观察时的执行次数。[验证口径](time-primitives.md#时间敏感与长任务)
