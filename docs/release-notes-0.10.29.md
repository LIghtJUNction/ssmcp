# 0.10.29

本版本修复 0.10.28 候选版本的跨平台发布检查，并保留该候选版本的本地总览、设备恢复、命令统计和 worker 调度功能。

## 修正

- 为 Linux 专用的 007 恢复辅助函数补充平台限定，解决 macOS 和 Windows 严格 Clippy 检查中的未使用函数错误。恢复凭据比较的单元测试仍在各平台保留。
- 更新资源目录回归测试，明确包含新增的 `ssmcp://recovery`。断开连接后的检查继续验证完整 URI 集合与原快照一致。

- 便携服务测试为经过认证的设备挑战请求提供明确的旧网关回退响应，并继续拒绝未知路由、无效凭据及非空请求对象。
- Windows 窗口验收等待应用首次 present 返回，检查真实客户区像素并保存截图；空白应用区域不再因标题栏可见而通过。验收同时保留进程归属、源码及二进制摘要和正常退出检查。

## 平台

Linux 与 macOS 是首要支持目标。Windows 客户端继续通过独立的原生构建、测试及窗口验收流程进行适配。
