# Next version

## 中文显示语言

状态：用户已提出，安排在 0.9.0 之后的版本。

默认显示语言保持英文。增加 `/language en` 与 `/language zh`，切换客户端导航、帮助、设置说明和本地状态提示；选项写入现有 `[ui]` 配置。切换即时生效，并在下次启动时恢复。

实现使用稳定的消息键和显式占位参数，避免按最终英文字符串做全局替换。用户输入、文件路径、命令、工具 schema 和原始工具输出保持原文；中文与英文界面读取同一状态。窄终端布局根据实际显示宽度处理中文，沿用现有 Unicode 光标规则。

验收覆盖：首次启动默认英文；两种语言通过斜杠命令互换；配置持久化；完整帮助可滚动；切换前后草稿、光标、收件人、问答和历史保持一致。
