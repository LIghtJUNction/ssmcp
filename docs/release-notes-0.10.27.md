# SSMCP 0.10.27

本版简化 worker 的默认启动方式，增加每个 worker 的日志窗口，以及版本、关于、插件管理和路径查询入口。

## Worker 直接启动

```sh
ssmcp
ssmcp --worker 2
```

`ssmcp` 打开交互界面；`ssmcp --worker 2` 打开两个任务槽的监控面板，等待已授权的外部 agent 分配和领取任务。无需填写 `--agent` 或 `--input`，也不会默认启动本地模型或 harness。后台运行使用 `--daemon`。连接地址继续复用现有配置和 `--server`。

每个 worker 分别显示状态和真实生命周期日志。左右键切换 worker，上下键、翻页键或面板内滚轮查看日志，`End` 恢复实时跟随。暂停查看时保留阅读位置；日志只保留最近的有界记录。worker 界面没有聊天输入框。

任务领取与完成报告分开记录。同一领取请求重试返回原 claim，完成必须由原领取者回报；取消中的任务继续占槽。worker 与服务器断开时，未确认的任务记为未知，不自动重派。外部 agent 的完成回报不会被表述为本机已观察到远端进程结束。[使用与边界](workers.md)

## 终端里的本地命令

| 命令 | 用途 |
| --- | --- |
| `/version` | 显示正在运行的客户端构建版本。 |
| `/about` | 打开独立关于页，显示用途、版本、许可证和项目地址。 |
| `/plugin` 或 `/plugin list` | 查看当前客户端的原生插件。 |
| `/plugin load NAME PATH` | 加载指定的本地动态库插件。 |
| `/plugin unload NAME` | 禁用插件工具并请求其工作线程停止。 |
| `/plugin help` | 查看插件命令和路径规则。 |

这些命令在当前客户端处理。选中其他消息收件人不会把它们作为消息发走；编辑队列中的正文时仍按普通文字处理。插件卸载不删除文件，也不强行终止正在执行的原生调用。[界面帮助](client-ui.md)

## 可组合的路径查询

```sh
ssmcp paths --list
ssmcp paths config history --plain
ssmcp paths history config --json
```

`ssmcp paths` 枚举十种实际位置，支持按名称组合并保留指定顺序。查询在连接和配置加载之前完成，不读取凭据内容，不创建目录；错误参数不会留下部分路径输出。[完整名称与环境优先级](paths.md)
