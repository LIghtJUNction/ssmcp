# ssmcp 0.9.0 会话交互升级

## 当前状态

最终本地验收已通过。本文对应运行时源码 `808703c7e3ff22520185083122ab8844d24fa84d`；客户端与服务器的实际安装回执将在部署完成后补入。本地验收完成于 2026 年 11 月 18 日 16:42（Asia/Taipei）。

## 使用变化

默认界面保留固定底部输入框和可折叠右侧面板，使用深色背景、橙色输入提示及蓝、绿、紫、黄语义配色。右下角显示项目名和可用的 Git 分支。顶部按实际观察到的工具调用显示 Active、Idle；断线与无法确认的旧调用分别显示 Offline、Unknown。调用者名称用于显示，不代表身份认证。

| 操作 | 行为 |
| --- | --- |
| Enter / Ctrl+J | 提交需求 / 换行 |
| ↑ / ↓ | 先按显示行移动，再浏览输入历史 |
| Tab | 在输入与活动内容之间切换焦点 |
| `/agents` | 查看共享同一客户端会话的调用者和登记成员 |
| `/queue` | 查看待交付要求；Enter 取回编辑，Delete 取消 |
| Shift+↑ | 取回最近一条待交付要求，等待服务器确认后编辑；暂存当前草稿、图片与目标 |
| Esc | 取回项尚未修改时恢复原草稿；已修改时保留内容并提示先完成或取消 |
| Ctrl+V / `/paste` | 粘贴剪贴板文字或图片 |
| `/attach PATH` | 添加图片文件 |
| `/images` / `/detach N` | 查看附件 / 移除指定附件 |
| `/copy` | 复制最近一条 Agent 消息的完整正文 |
| F3 / `/sidebar` | 折叠或展开右侧状态面板 |
| Ctrl+O / `/audit` | 查看源码与执行细节 |
| `/reload` / `/restart` | 重启客户端并交接草稿、附件与确定尚未交付的要求 |
| F5 | 重载显示配置 |

用户继续输入时，要求进入本会话队列；下一次访问本客户端且符合接收目标的工具响应携带这些要求，同时保留原工具结果。已交付表示已附加到响应，不能证明模型已经阅读。已交付内容不会被取回功能伪装成“未发送”，也不会在重载后自动重发。

图片与文字共同编辑、取消和交接。图片通过真实 MCP image 内容块交付，需要客户端与服务器均支持协议 v8；旧 v7 客户端继续使用文字功能。每条要求最多 4 张图片，编码后单图最多 1 MiB，并有总量限制；大图按限制转换，失败会保留草稿并提示。

Agent 使用 `say(clientId, {text, kind})` / `ssmcp.ui.message` 将进度、解释、问题及答复写入当前客户端。答复可显示为 UPDATE 或 ANSWER，`/copy` 复制原始正文。发送消息可以领取追加要求；默认读取消息历史不领取。消息历史属于当前进程，不跨重载恢复。

详细脚本及识别语言的代码块显示关键词、函数、字符串、注释和数字的语法色；Agent 答复中的代码块使用相同渲染。diff 保留双侧行号、增删符号与区段色。关闭颜色后文字、符号与行号仍保留。

## 本地验收

所有下列运行均绑定上述同一份源码和同一批 release 二进制。

| 范围 | 结果 |
| --- | --- |
| `cargo fmt --check` | 通过 |
| 严格 Clippy（全部 target、`-D warnings`） | 通过 |
| Rust 库测试 | 814 通过，0 失败，9 忽略 |
| 真实终端预览 | 42 项通过 |
| 输入、队列、重载 | 88 项通过 |
| 中继会话输入与交接 | 45 项通过 |
| 图片、Shift+↑、答复、复制 | 121 项通过 |
| 仪表盘与连接行为 | 84 项通过 |
| 端到端断言合计 | 380 项通过 |

Shift+↑ 的实际终端验收发现并修复了连续 Escape 序列的时序问题：新的组合键现在会正确结束前一个待决 Escape，不会将 `[1;2A` 写入草稿。验证保留真实键盘输入，没有通过延长等待掩盖问题。

验收覆盖 Linux 上的隔离 PTY、真实客户端/中继进程与合成数据。剪贴板测试使用独立的测试所有者，不改写用户实际剪贴板。生产连通性、图片交付及升级后的旧版本兼容性将记录在独立部署回执中。
