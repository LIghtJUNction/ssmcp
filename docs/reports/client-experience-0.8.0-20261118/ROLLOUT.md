## 开发机的独立入口

候选包已解包到专用版本目录，并创建 `~/.local/bin/ssmcp-0.8.0` 入口。可以立即预览新的默认界面：

```sh
~/.local/bin/ssmcp-0.8.0 --version
~/.local/bin/ssmcp-0.8.0 ui preview
```

该入口不替换默认的 `ssmcp`、mise shim、认证文件或会话配置，也没有重新加载现有连接。准备期间观察到默认 0.7.4 客户端摘要发生变化，因此保留并行工作的安装结果。独立入口来自上表中的同一包，其程序摘要已核对。[安装记录](versioned-install.json)

新版客户端可以使用已有连接方式；用户要求队列与定向成员仍需要网关支持协议 v7。仅启动新版客户端不会把仍在运行的 0.7.2 网关升级。

## 服务器隔离试运行

试运行使用独立 loopback 端口、systemd unit、账号存储、OAuth 客户端注册表、审计目录和 Unix socket。12 项脚本检查均通过，包括包身份、二进制版本、健康状态、OAuth discovery、未认证 MCP 请求拒绝、授权页面、DCR 跨试运行服务重启持久性及注册表权限。[试运行结果](server-stage.json)

试运行结束后关闭了该临时服务。生产网关前后的 PID、磁盘与运行中二进制摘要、包版本和配置摘要均相同；没有对生产服务执行 restart、reload 或包安装。此结果证明隔离网关启动与 OAuth 注册持久性通过，不代表真实 GitHub 账号、公网 TLS 或线上队列已完成升级后的验收。

阶段回执绑定源码提交、包摘要、版本及生产状态，并只在一小时内有效。生产切换前必须重新核对状态；回执过期时重新执行隔离试运行，不能跳过该校验。

## 回滚与待执行步骤

当前 0.7.2 回滚包已复制到开发机的私有备份目录，并在复制前后检查 SHA-256、大小、权限和包内两个程序。原服务器回滚包继续保留。[回滚归档记录](rollback-archive.json)

公开 JSON 保留制品摘要、数值和检查结果；私有文件路径作了规范化，生产配置摘要只记录前后相等的事实。实际操作路径与原始记录保留在私有操作材料中。
