# SSMCP v0.10.23：客户端资源配对测量

## 结论与范围

run-04 的 12 次测量全部有效。六对结果中，候选的合并 idle CPU 均低于基线，RSS/PSS 均高于基线；40 条短命令批次的耗时也均略高。minimal 的合并 idle CPU 配对变化中位数为 **−0.1874 个单核百分点**，synthetic 为 **−0.2502 个单核百分点**。工作后 RSS 的配对增加分别为 **804 KiB** 和 **756 KiB**，工作后 PSS 的配对增加分别为 **865 KiB** 和 **1017 KiB**。

这是 cbe 基线到完整 v0.10.23 候选的资源取舍。产品代码、工具目录、zuse/zcall 等最终依赖版本都包含在比较范围内；数据不能归因于某一项优化。每个负载只有 3 对，没有统计显著性或长期稳定性结论。

## 有效性与干扰

12/12 报告通过真实终端、精确草稿、完整阶段时长、命令输出、catalog 稳定性、隔离和源码/二进制身份检查。任务退出码 0，总用时 215.519 秒。24 个 idle 窗口的实际时长合计 192.002092 秒，CPU 样本覆盖 191.397 秒，最短单窗口 7.950 秒。

公共 Cargo flock 覆盖整个批次，结束后已释放并验证可重新取得。428 次整机观察没有检测到 Cargo/compiler/E2E 竞争。背景系统负载仍存在：24 个 idle 窗口的整机 CPU 忙碌中位数范围为 2.27%–7.84%，这些中位数的中位数为 5.32%，单次整机观察峰值为 13.78%（此处 100% 表示所有 24 个 CPU，和下表单核百分比不同）。0.5 秒观察间隔无法排除更短的未捕获负载。

客户端 swap 全部为 0。结束时真实私有挂载 `/var/tmp/benchmark-bin/ssmcp` 无进程残留。主 job 为 `26c4545eae1eab8d27485f4a48077d3c-7f7`，最终日志为 `LOCK_RELEASED`。

## CPU 结果

CPU 使用客户端进程 `/proc/PID/stat` 的 user+system 时间，**100% 表示一个逻辑核心**，不含任何子进程。合并值由两段 idle 的 CPU 秒数之和除以实际采样秒数之和计算。

下表范围为 3 次运行或 3 个配对差值的最小/最大值，不是置信区间。配对变化定义为同一 pair 的“候选−基线”，再对 3 个差值取中位数；它不一定等于两个独立中位数相减。CPU 变化列的单位为单核百分点。

| 负载 | 指标 | 基线中位数 [最小, 最大] | 候选中位数 [最小, 最大] | 配对变化中位数 [最小, 最大] |
|---|---|---:|---:|---:|
| minimal | 工作前 idle CPU（单核 %） | 0.6277 [0.5023, 0.7513] | 0.5019 [0.3767, 0.5022] | -0.1256 [-0.2494, -0.1255] |
| minimal | 工作后 idle CPU（单核 %） | 0.7511 [0.6265, 0.8779] | 0.5024 [0.5021, 0.6276] | -0.2490 [-0.2503, -0.1241] |

系统 CPU 时钟为 100Hz，一个 tick 为 10ms；合并两个约 8 秒窗口时，一个 tick 对应约 0.06257–0.06279 个单核百分点，单个 idle 窗口约 0.125 个百分点。小于或接近这一粒度的差异不能作精细解释。

## 原始文件、排除项与未测范围

本目录的 raw-runs.csv 包含 12 次运行的原始 CPU/RSS/PSS、阶段时长和环境数据；raw-phases.csv 保留所有阶段的样本统计，缺失观测为空值；paired-summary.csv 包含每个指标的基线/候选中位数、范围及配对变化；analysis-data.json 包含完整摘要、校验信息和目录负载记录。

测量原始证据位于开发机 `/var/tmp/ssmcp-controls-20261121/perf-final-results/run-04/`。每个 run 子目录保留 report.json、validity.json、ambient.json 与 stdout/stderr。completion-audit.json 保存最终完整性和清理检查；summary.json 是冻结 runner 的原始汇总，未改写。

旧的 17 次 raw-PTY 无效记录、4 次较早中断记录、run-01 的 12 次 superseded v0.10.21 记录，以及 run-02/run-03 的未完成 v0.10.22 尝试均未纳入。b743 的计划仅准备过，未执行。

未测真实模型、宿主键鼠输入、浏览器/显示 worker、socket/agent 专项吞吐、活跃长倒计时的 CPU、长时间内存增长、daemon 或完整进程树内存，也未在 macOS/Windows 上测量。已有功能验收和正式 Release 的跨平台结果不由这份性能报告替代。
