产品定位：
ssmcp 是把本地开发机连接到中继服务器、供已授权调用方通过 MCP 使用的远程工具服务，提供文字、文件和端口转发等能力。它不是模型会员、模型 API 转售或 Astra Pro 反向代理，不要这样宣传。

商品与计费：
1. 普通用户每月有 1 GB 免费流量；管理员不限额。
2. 付费商品为“ssmcp 月度转发流量”，初始价格为人民币 1 元 / GB。
3. 购买额度与免费额度都属于当月，未使用部分不结转下月。在商品页、支付前说明和用户协议中写清楚。
