# SSMCP 0.10.21

- **原生消息与组发。** 在获准的设备账户收件箱和已验证线程之间双向发送文本。单发使用精确地址，组发只发送给显式选中的 1–32 个收件人，并分别显示回执。回执记录入队、放入工具响应和确认收取等阶段，任务执行情况由收件方另行报告。 [原生消息指南](thread-messaging.md)
- **按所选收件人使用 `/send`。** 命令沿用最近一次明确选择的组、原生收件人或本地目标。原生消息发送原文，本地监听仍准备文件和技能引用。组发部分成功时保留草稿，重试沿用原组及各目标的请求 ID。 [发送与回执](force-send-listener.md)
- **引用与草稿取回。** 普通要求中的缺失 `@file` 或未知 `$skill` 会提示引用不可用，符合大小限制的正文仍可发送。空输入框按 ↑ 可取回仍待交付的要求，确认后移除对应的待交付记录。跨连接恢复去向未确认的要求时，原尝试保留，另起一份待编辑的请求。 [引用和队列](client-ui.md#输入要求与队列)
- **身份与历史描述。** 界面区分操作系统 PID、中继连接 ID 和逻辑线程 ID。在线角色短摘要上限为 128 个 UTF-8 字节。本地历史标题与摘要可以单独保存，分别最多 256 和 2048 个 UTF-8 字节。 [成员身份](client-ui.md#agent-面板与成员身份) · [历史描述](client-ui.md#本地历史标题与摘要)
- **历史与审计。** 对话按所选历史显示带归属的任务输出和原生回复，Logs 与 Tasks 保留跨会话审计。晚到的回复可写回仍可写的原会话，`/copy` 继续使用所选历史的回复。 [本地消息与历史归属](client-ui.md#本地消息与回答问题)

连接 0.10.13 旧中继时，可用 `--account-compat` 和该中继已验证的自身账号注册连接。原生消息另需客户端与中继支持，`messages.*` helper 也须由中继提供。 [账号兼容说明](client-accounts.md) · [能力要求](thread-messaging.md#兼容范围)
