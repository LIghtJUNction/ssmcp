运营者与联系

李俊运营 ssmcp 托管中继服务。隐私请求可发送至 ssmcp@lmm.best。

中继内容

通过 ssmcp 转发的文字、文件和端口数据由中继处理并转发，服务端不将转发载荷作为历史内容存档。你的客户端、目标服务及第三方工具可按各自设置保存内容。

账号、用量和订单

GitHub 登录用于核验身份。服务保存 GitHub 账户编号、登录名、注册的服务器用户名和设备授权信息，用于账号绑定和访问控制。服务记录按账号与自然月汇总的字节数，以计算额度。开通购买后，订单标识、购买账户、数量、金额、币种、付款状态和有效月用于对账、发放额度和处理退款。支付卡信息由 Waffo Pancake 处理。

日志和保留

服务端审计日志滚动保留最近 7 天，最多 20,000 条。前置代理维护访问日志，用于排障和安全。账号及授权记录按账号运行需要保存，用量及交易记录按服务运行、对账、争议和适用义务所需保存。月底清零的是可用额度。

保护与服务提供方

站点传输使用 HTTPS。服务器以服务账户权限限制对账号及日志的访问。GitHub 处理登录验证，基础设施服务商承载中继及站点运行，Waffo Pancake 在购买时处理结账和支付。访问、更正或注销可通过下方邮箱提出。

访问、更正和删除

你可通过 ssmcp@lmm.best 申请查询、更正、注销或删除。必要时我们会核验你的身份。适用义务要求保留的交易或安全记录会限制用途。支付平台持有的数据可向该平台查询。
