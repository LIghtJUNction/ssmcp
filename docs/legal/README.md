# 托管流量服务条款模板

本目录提供用户要求的两个仓库模板，覆盖文本数据中继、文件互传和端口映射。模板与实际产品规则分开保存；这些文件不会自动发布到线上，也不会开启支付。

- [用户协议模板](terms-of-service.template.zh-CN.md)
- [隐私政策模板](privacy-policy.template.zh-CN.md)

## 已确定的产品规则

| 项目 | 本轮要求与实现约定 |
| --- | --- |
| 免费流量 | 普通账号每个自然月 1 GB，1 GB = 1,000,000,000 字节 |
| 管理员 | 由服务端验证的身份决定，月度额度不受限，界面显示“无限” |
| 默认基础单价 | CNY 100 分／GB，即人民币 1 元／GB |
| 购买方式 | 单次购买；未实现自动续费 |
| 有效月份 | 当前自然月，次月第一天 00:00 到期，不结转 |
| 默认月份偏移 | UTC+08:00；实际值由服务器配置决定 |
| 月售卖上限 | 单独配置；未指定容量时不启用购买 |
| 支付到账 | 服务端验证订单与付款信息后幂等到账；成功跳转页不能充当证明 |
| 跨月晚到账 | 旧订单不转成新月额度，保留记录并人工核对退款 |
| 计量 | 账号内上下行合计、包含应用协议封装；成功预扣后的失败或重试不自动冲正 |

“月度额度不受限”只描述管理员额度，不描述网卡能力、速率限制或服务可用性。付费销售容量应留足免费用户和运营需要的资源；配置容量本身不会替运营者测量供应商剩余流量。

## 发布前需要填写的真实信息

运营者名称、联系渠道、生效日期、实际月份时区、退款规则、服务器和供应商处理地区、各类数据保留期限、注销与权利请求流程、重大变更通知以及适用的争议处理安排均保留为占位符。未核实前不得编造登记主体、备案或认证、法定保存期限，也不得声称“不记录内容”“绝对安全”或“端到端加密”。

这两份文件是可修改模板，尚未经过针对特定运营主体和司法辖区的法律审查。正式对外发布前，应结合实际部署、支付平台合同和适用规则完成审核，并在购买前展示明确的版本和关键交易条件。

## 与代码的对应关系

产品计量和扣量规则由服务端强制执行，不能只依赖页面提示。审阅时应核对：

- `src/broker/traffic.rs`：身份、月份、额度查询与付费到账边界。
- `src/portal/traffic.rs`：耐久流量账目、跨月状态与订单去重。
- `src/user_policy.rs`、`src/device.rs`、`src/broker.rs`：上下行收费边界和不同传输入口。
- `src/commerce.rs` 与 `src/commerce/`：价格、当月库存、订单持久化、付款核验。
- `src/portal/commerce.rs`：已登录购买者、购买前展示与请求防护。
- [命名账号说明](../named-accounts.md)：账号与管理员的服务端权限来源。

以上路径对应本轮功能分支；与功能合并时应重新核对最终文件位置和行为，不能把文档中出现的路径当成代码已经发布的证明。

## 写作与事实复核

文档按用户指定的 [Research Paper Writing](https://github.com/Master-cai/Research-Paper-Writing-Skills/blob/main/research-paper-writing/SKILL.md) 方法整理：每节围绕单一问题，先说明结论，再给必要条件；按“声明—依据”复核，无法验证的内容保留为待填写项。

| 核查问题 | 本模板处理 |
| --- | --- |
| 读者能否看清价格和到期条件？ | 将 1 元／GB、自然月到期、默认时区和单次购买直接列明 |
| 是否把文件大小误当作计费字节？ | 明示上下行、协议封装、预扣失败与重试口径 |
| 是否把支付跳转当成付款凭据？ | 明示必须由服务端核验，重复回调只到账一次 |
| 是否编造法律或隐私承诺？ | 主体、期限、地域、退款和法律安排均保留真实填写位置 |
| 是否忽略源码与托管服务的区别？ | 保留仓库开源许可证的效力，不用托管协议替代它 |

支付平台资料只用于确认外部支付环节及其政策入口；模板没有复制其完整法律条款。参考入口核对日期：2026-11-18。
