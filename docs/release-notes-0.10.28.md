# SSMCP 0.10.28

本版本改进已保存会话与在线客户端的总览、命令资源统计、设备身份与恢复，以及 worker 的空闲调度。Linux 与 macOS 是首要支持目标；Windows 客户端继续通过原生构建和验收提供支持。

## 主要变化

- **会话总览。** 分开显示已保存的定义与当前在线连接，支持明确选择查看目标。探测数量与耗时都有边界，缺少的指标保持未知。
- **命令详情与统计。** 原生命令保留真实执行 ID、完整只读参数和退出状态。Linux 记录实际 CPU 时间与峰值内存；启用磁盘跟踪时，显示实际观察到的逻辑字节变化。
- **设备身份与连接恢复。** 稳定设备身份独立于每次连接 ID。恢复沿用原账号和授权，保留原操作依据；显式停止、撤销授权和未知执行结果分别处理。
- **Linux 资源限制。** CPU 与内存限制通过实际 systemd/cgroup 资源边界实施，并核对内核状态。平台能力和未支持的限制明确报告。
- **空闲 worker 调度。** Dreaming 可以使用真实 standby 容量，不必等待其他 worker 全部空闲；维护任务继续通过真实 claim 和完成回执管理。
- **界面与验收。** 保持只读任务详情、连接状态和语法高亮的真实渲染路径；Windows 桌面验收增加实际窗口、进程、截图和退出状态证据。
- **回复与等待。** 必读指引要求通过 SSMCP 原生回复工具与用户沟通，并在回答后等待真实用户输入。
- **发布来源。** `zi18n` 与 `zhex` 纳入精确 Git 源码和 registry 导出验证；发布脚本继续分别检查独立依赖与 SSMCP 自身的制品。

## 安装

从 [v0.10.28 Release](https://github.com/LIghtJUNction/ssmcp/releases/tag/v0.10.28) 选择对应系统和架构的归档，并核对 `SHA256SUMS`、`release-manifest.json` 与实际程序的 `--version`。完整步骤见[版本发布与跨平台安装](releases.md)。

原生 GUI、Windows 实际窗口及各架构的验收范围以本次 Actions 和随附收据为准。发布附件、服务器部署与运行中客户端的重载分别记录。
