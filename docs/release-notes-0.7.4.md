# 0.7.4

新增 `ssmcp --tty kitty`、`ssmcp --tty ztty` 和终端包装器入口。客户端保留一个观察窗口，顺序命令复用，重叠执行时自动增加窗口；多余空闲窗口三分钟后关闭。窗口显示工作目录、命令、输出和结束状态，手动关闭后自动重新打开，正在运行的命令继续执行。

Unix 上的受管命令使用真实输出 PTY，终端程序显示同一次执行产生的内容。命令返回 `output_mode: "pty"` 与 `tty_slot`，stdout 中包含 stdout/stderr 合流；未启用 `--tty` 时保留原有分离输出。标准输入、执行期限、进程树取消和完整输出保存延续原有契约。交互 shell 及原生提供方命令也接入观察窗口，原生提供方仍负责自身执行和权限处理。

终端启动支持 Kitty、ztty 等常见参数约定，并允许用可执行包装器适配其他终端。会话保存与恢复保留 `--tty`。每个窗口按需保留 128 KiB 输出尾部，重新连接时回放；超过尾部容量会提示读取完整输出。

[验证记录](validation-terminal-observers.md)列出了 50 个本地 Rust 单元/回归测试，以及记录器、真实 Kitty、真实 ztty 各七组端到端验收结果。记录同时说明 Linux 运行验证、其他平台边界和原生协议夹具的范围。
