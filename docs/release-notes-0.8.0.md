# 0.8.0

客户端默认使用连续活动流、多行输入框和可折叠状态栏。运行期间可以追加用户要求，并在队列中取回编辑、取消或重新选择接收成员；下一次符合授权与目标的 `code_mode` 响应携带这些要求。成员列表使用真实登记的 agent ID，显示名称不承担身份验证。

日志支持直接滚轮浏览、文本搜索和命令／错误类别筛选，按调用展示命令、工作目录、输出、退出码和耗时。原终端显示区域改为原始编排源码审计，支持上下键浏览、Enter／右键展开、左键返回、行号和语法高亮。独立终端接口与 0.7.4 的可复用命令观察窗口继续保留。

新增 `/help`、`/queue`、`/agents`、`/audit`、`/filter`、`/theme`、`/sidebar` 和 `/reload` 等交互入口。六种内置主题支持逐项颜色覆盖；布局、侧栏宽度和面板顺序可以保存。`ssmcp.ui.get/set/action/filter/queue` 提供独立状态与控制接口，`get` 支持字段投影和分页，方便自定义前端只读取所需内容。

`/reload` 重新执行 ssmcp 客户端，保留草稿与确认可恢复的未交付要求；交付状态不确定的记录等待用户复核，不自动重发。它沿用连接的任务清理规则，不重启外部模型对话。

## 兼容性

- 用户要求队列和定向成员需要客户端、网关均支持协议 v7；原始源码审计需要 v6。连接保留 v7 → v6 → v5 → v4 协商回退。
- “已交付”表示附加到工具响应，不证明模型已经阅读或执行。没有下一次合格调用时，要求继续等待。
- 前台直连支持本地输入队列；`ssmcp attach` 的本地输入框暂不转发要求，可通过后台连接的 `ssmcp.ui.queue` 管理队列。
- 客户端安装、网关升级与已连接进程的重载分别生效。更新磁盘文件不会自动升级现有会话；网关重启会断开现有连接，并按生命周期结束所属任务。

README、客户端指南、man page、配置示例及源码包中的验收脚本已同步更新。具体按键与接口见[客户端指南](client-ui.md)；构建和发布状态应以对应提交的验证记录与正式发布附件为准。
