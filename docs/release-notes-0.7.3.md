# 0.7.3

账号登录、设备邀请、SSH 会话和 MCP 统一使用同一个网关进程。新增标准 `setup-server` 命令：检查或迁移旧双进程配置，保留账号数据与 TLS 配置，验证登录 API，失败恢复原配置；重复执行不重启正常运行的网关。Linux 归档及源码安装均提供该命令。

修复 SSH HostName 指向地址时的 Portal HTTPS 域名推导。公钥登记与服务器同步使用 OpenSSH 校验，支持安全密钥等公钥类型；自动设置允许选择公钥文件或粘贴公钥。

更新部署指南，明确账号 CLI 所需的单进程拓扑；隔离部署验证使用独立账号、审计目录及管理 socket。修正后台会话恢复测试中的短暂继承锁竞争。
